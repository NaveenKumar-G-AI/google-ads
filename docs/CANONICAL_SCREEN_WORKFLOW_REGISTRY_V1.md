## Workflow registry

### WF-001 — First paid customer activation
Signup → Organization → Billing → Google Ads connect → Account selection → Business Truth → Measurement check → Initial sync → Initial analysis → Command Center.

### WF-002 — Recovery Case lifecycle
Finding → Recovery Case → Evidence review → Proposal → Approval → Validation → Apply → Post-action monitoring → Verification → Recovery result → Close/Reopen.

### WF-003 — Agency onboarding
Agency org → Team invites → Client workspaces → MCC connect → Accounts → Account owners → Business Truth templates → Portfolio monitoring → Scheduled reports.

### WF-004 — Alert lifecycle
Monitor detects condition → deduplicate/group → severity → alert → notification → acknowledge → investigate → action/recovery case → resolve → history.

### WF-005 — Automation lifecycle
Strategy create → dry run → review → schedule → run → proposal/action → verification → alert on failure → history.

### WF-006 — Measurement failure
Tracking monitor → measurement-confidence downgrade → affected findings marked constrained → alert → repair → revalidation → confidence restored.

### WF-007 — Billing failure
Provider event → reconcile → entitlement downgrade → preserve read/rollback → notify owner → retry/recover → restore entitlement.

### WF-008 — Data deletion
Authorized request → scope preview → legal/retention checks → confirmation → export option → revoke integrations → delete/anonymize → immutable deletion audit.

### WF-009 — Support incident
Customer ticket → tenant/account context → operator triage → job/integration/billing diagnostics → safe remediation → customer update → close.

### WF-010 — AI release safety
Shadow predictions → blinded labels → evaluation → release → limited production routing → drift reviews → trip/revoke → deterministic fallback.
